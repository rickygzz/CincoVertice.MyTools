# My Tools User Guide

For the version you have, choose **About My Tools...** in the tray menu.

## Overview

**My Tools** is a Windows utility that lives in the system tray (the icon area of the taskbar). It gives you global hotkeys for small tools: a calculator with unit and time zone conversion, a screen snipping tool with an annotation editor, a color picker, a diagram editor, a "mouse mover" you can switch on and off, window zones to snap windows into, a checker and fixer for C# code formatting, and a small scripting language for automating typing, the clipboard, dialogs and launching things.

There is no installer. You download a zip, unpack it, and run one program.

This guide is for people who download and use the app. It covers every tool, the settings files you can edit, and what to do when something does not work.
