# Try MyTools with sample files

You do not need your own documents to explore the comparer, diagram editor, or scripts.

Start with the [step-by-step tutorials](../user-guide/16-tutorials.md). See the completed examples in the
[screenshot tour in the README](../../README.md#see-it-in-action).

| Sample | What to do with it |
|---|---|
| [weekend-before.txt](samples/weekend-before.txt) and [weekend-after.txt](samples/weekend-after.txt) | Save both files, then open them in **Compare files...**. Look for changed times, lunch plans, the packing list, and the day to share the plan. |
| [weekend-plan.svg](samples/weekend-plan.svg) | Download the raw file and open it with **File > Open...** in the diagram editor. Move a shape and watch its connectors follow. This is an editable MyTools diagram. |
| [SearchTheWeb.mts](samples/SearchTheWeb.mts) | Read the script, then copy it into a new script in the config editor. It asks what to search for, offers the clipboard text, and opens Google when you confirm a nonempty query. |

On GitHub, open a sample file and use **Download raw file**. Work on copies if you want to keep the original examples.

The sample text files and script are source-controlled. The screenshot fixture regenerates the SVG from the same
diagram model used for its screenshot; see [maintaining the assets](../marketing/README.md).
