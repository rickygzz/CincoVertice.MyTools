# Short demos for MyTools

Record real interactions with sample data on a clean desktop. Show one result at a time and keep captions short.
The timing below is a planning guide, not a claim about how quickly every task will run.

## A 60-second introduction

| Time | What to show | Caption |
|---|---|---|
| 0–5 s | MyTools tray icon, then the Actions menu | Everyday Windows tools, one shortcut away |
| 5–17 s | Ctrl+Alt+S; capture the sample checklist; add an arrow and short label | Make a screenshot easy to understand |
| 17–25 s | Ctrl+Alt+T over clear sample text; paste into a blank document | Copy words from a picture |
| 25–32 s | Calculator: `10 km to mi`, then history | Calculate and convert without leaving your task |
| 32–42 s | Open the two weekend text samples; jump between changes | See what changed—and edit either side |
| 42–50 s | Open the sample SVG; move one box and show the connector following | Put a plan into a picture |
| 50–56 s | Show zones while dragging two sample windows into place | Give your windows a place |
| 56–60 s | Return to the tray and show the repository/download link as an end caption | MyTools · Free and open source · Download on GitHub |

For this introduction, use a separate recording tool or a separate capture session: selecting and stopping MyTools'
own recorder while demonstrating its recorder changes what is being captured. No soundtrack or narration is required;
captioning makes the demo understandable without audio.

## Before sharing a recording

Watch the entire exported file. Check that the first useful action is visible, the pointer and labels can be followed,
the shortcut shown matches the app, and no unrelated window or notification appears. Use the sample notes and SVG
instead of personal documents. Keep an MP4 master; export a short GIF only when motion adds something to the post.
