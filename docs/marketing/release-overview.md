# MyTools — everyday Windows tools, one shortcut away

Take a screenshot and make it clear with arrows, labels, and numbered steps. Record a quick how-to. Compare two
versions of a note. Draw a plan, convert a measurement, and organize your windows—from one Windows tray app.

MyTools is free and open source. Download the Windows ZIP, extract it into a writable folder, and run
`CincoVertice.MyTools.Ui.Win.exe`. There is no installer and no separate .NET runtime to install.

Try these first:

- **Ctrl+Alt+S:** snip part of your screen and explain it with arrows and text.
- **Ctrl+Alt+T:** capture words on screen and paste them as text.
- **Ctrl+Alt+R:** record a selected area, then save MP4 or GIF.
- **Ctrl+Alt+C:** calculate or convert; try `10 km to mi`.
- **Ctrl+Alt+D:** draw a diagram and save editable SVG, PNG, or PDF.
- **Tray > Compare files...:** see changed lines and words, then edit either side.

There is more in the tray: custom window layouts, a color picker, a mouse spotlight, Keep Awake, customizable
shortcuts, and scripts for repeated tasks.
